# my-oddly-satisfying-animation

Three.js でつくった「見ていて気持ちのいい」ループアニメーション集。
12 のシーンを自動／手動で切り替えながら眺められます。

就寝前に眺めることを想定して、色と明るさは全体に落としてあります（後述）。

## 起動

```sh
npm install
npm run dev      # http://localhost:5173/
```

その他のコマンド:

```sh
npm run build      # 型チェック + dist/ へ静的ビルド
npm run preview    # ビルド結果を確認
npm run typecheck  # 型チェックのみ
```

`vite.config.ts` で `base: './'` にしてあるので、`dist/` はどのパスに置いても動きます。

## 操作

| 操作 | 内容 |
| --- | --- |
| `1` – `9` / 画面上部のタブ | シーンを直接選ぶ（10 以降はタブか `←` `→` で） |
| `←` `→` | 前後のシーンへ |
| `Space` | 自動切替（34 秒間隔）の ON / OFF |
| `S` / 右下の「♪ 効果音」ボタン | 効果音の ON / OFF（既定は OFF） |
| ドラッグ / ホイール | 視点の回転・ズーム（放置するとゆっくり自動回転） |

URL の `#2` のようなハッシュで開始シーンを指定できます。切り替えるとハッシュも追従するので、
気に入った状態のリンクをそのまま共有できます。

## 効果音

各シーンには、その動きに合わせた効果音が付いています。右下のボタンか `S` キーで
ON / OFF でき、選んだ状態は `localStorage` に残ります。ブラウザは操作なしに音を
出せないので、ON で終了した場合も次に開いたときの最初のクリック／キー入力まで
待ってから鳴り始めます。

音声ファイルは持たず、`src/audio.ts` が Web Audio API の発振器とノイズだけで
組み立てています。用意しているのは 4 種類だけです。

| 音 | 中身 | 使いどころ |
| --- | --- | --- |
| `pluck()` | 正弦波 + 薄い倍音を指数減衰 | 珠・ドミノ・振り子が当たる音 |
| `drop()` | 音程を滑らせた短い正弦波 | 雨だれ、泡が水面へ抜ける音 |
| `air()` | 帯域を絞ったノイズ | 風、衣ずれ、輪が通り過ぎる音 |
| `drone()` | わずかに離調した 2 本の持続音 | 呼吸・水底・回廊の低い響き |

入眠前に聴く前提なので、音程はペンタトニック（`tone()`）だけを使ってどう重なっても
濁らないようにし、出力全体を 2.4kHz のローパスと長い残響に通して「遠くで鳴っている」
状態に寄せています。音量も低めに固定しています。

鳴らすタイミングは、映像と同じ時刻 `t` から逆算しています。たとえばドミノなら
「`t / CYCLE - u` が整数をまたいだ瞬間 = その牌が倒れ始めた瞬間」です。この
「またいだ回数」を数えるのが `ticker()` で、音が OFF の間 `sound()` は呼ばれないため、
再開時にまとめて鳴らないよう最大 2 回で頭打ちにしています。

シーンが密なもの（振り子 26 本、ドミノ 84 枚など）は数本おきにしか鳴らしていません。
全部鳴らすと音が団子になり、眠るどころではなくなるためです。

## 色づくり

入眠前に眺める前提なので、青い光をほぼ使っていません。色は `src/palette.ts` の
`ember()` に集約してあり、色相は「くすんだ薔薇 → 赤 → 琥珀」の帯だけを使い、
明るいところほど彩度を落として白熱電球のような色に寄せています。シーン側は
0〜1 の値を渡すだけなので、パレットを差し替えれば 12 シーンの色味が一度に変わります。

トーンマッピングの露出は 0.92、ブルームは強さを落として半径を広げ（0.42 / 0.85 / 0.28）、
輪郭がじわりとにじむ程度に留めています。光源もろうそくに近い色温度で揃え、
UI の文字色やタブも同じ暖色にしてあります。

## 画面サイズへの追従

`PerspectiveCamera` の `fov` は垂直方向なので、画面が縦長になるほど水平画角が削れて
被写体が左右にはみ出します。`stage.ts` の `fitScale()` が 16:9 との比からカメラの
引きしろを返し、`main.ts` がシーンのカメラ位置をその分だけ後ろへずらします
（引きすぎを避けるため 3 倍で頭打ち）。引いた分は霧が濃くなるので、`FogExp2` の
density も同じ比率で薄めています。

`devicePixelRatio` はウィンドウを別解像度のディスプレイへ移すと変わるため、
`resize()` で毎回 `setPixelRatio()` を入れ直し、さらに resize イベントを伴わない
変化に備えて `matchMedia('(resolution: Ndppx)')` の change も監視しています。

## 構成

```
src/
├── main.ts            シーン切替・カメラ補間・メインループ
├── stage.ts           レンダラ / カメラ / ライト / ブルームの共通設定
├── palette.ts         全シーン共通の暖色パレット
├── audio.ts           Web Audio API による効果音（音声ファイルは持たない）
├── ui.ts              タブ・タイトル・キーボード操作
├── types.ts           SceneModule インターフェース
└── scenes/            シーン本体（1 ファイル 1 シーン）
```

シーンを足すときは `src/scenes/` に `SceneModule` を 1 つ書き、`src/scenes/index.ts` の
`SCENES` に加えるだけです。`build(root)` で追加したものは切替時に
`disposeGroup()` がまとめて破棄するので、後始末は不要です。

効果音を付けるなら、任意の `sound(t, dt, sfx)` を足します。音が ON のときだけ
呼ばれるので、ここに映像へ影響する処理は書かないでください。`ticker()` を使う
場合は、シーンを開き直すたびに位相が 0 へ戻るよう `build()` で作り直します。
